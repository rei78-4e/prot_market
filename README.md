# めぐる団地 — 防災フリマ（デモ）

引換券と名札を使った、防災フリマの支援デモです。ものの循環と、売った人への声かけを支援します。

## 画面

- `dist/index.html`：利用者画面。商品一覧と個人情報の2タブ
- `dist/admin.html`：運営画面。商品の登録・削除、乾電池の回収、名札とラベルの印刷
- `dist/app.js`：共通ロジック（引換券、オプトイン、保存、写真の縮小）
- `dist/user.js` / `dist/admin.js`：各画面の操作
- `dist/style.css`：共通スタイル
- `dist/assets/`：商品画像6枚（WebP、合計約160KB）

外部のWebフォント・画像サービスは使いません。表示に必要なものはすべて `dist` に含まれます。

## 仕組み

- 売る人は受付で商品を預け、5段階の引換券（1・2・3・5・10枚）を受け取ります。
- モバイルバッテリーは運営が回収し、1個につき引換券2枚を渡します。
- 乾電池は運営画面で重さを入力して回収します。50gで引換券1枚、端数は切り捨てです。モバイルバッテリーとは別に計算します。
- 運営が商品や乾電池の回収を登録すると、売る人の引換券合計が利用者画面に反映されます。
- 商品一覧に出すのは一般物だけです。危険物は運営画面の回収リストにだけ表示します。
- 売る人の名前・部屋・連絡先・顔写真はすべてオプトインです。オンにした項目だけが一覧・名札・ラベルに表示されます。
- 名札には売った人の情報と、売ったもののサムネイル一覧を印刷します。商品ラベルは1点ずつ印刷できます。

## 設定

`dist/app.js` の `CFG` で変更できます。

```js
const CFG = {
  hazardTickets: 2,          // モバイルバッテリーは1個2枚
  tiers: [1, 2, 3, 5, 10],  // 一般物の引換券5段階
  batteryGramsPerTicket: 50, // 乾電池は50gで1枚
  photoEdge: 1000,          // 保存する写真の長辺
  photoQuality: 0.78,
};
```

## 起動

```sh
npm install
npm run dev
```

- 利用者： http://localhost:8787/
- 運営： http://localhost:8787/admin.html
- 静的サーバーで `dist` を配信しても動きます。例：`python3 -m http.server 8080 --directory dist`
- ロジックの確認： `npm run check`

## デモの前提

- データは各ブラウザーの localStorage にのみ保存されます。認証・サーバー・決済はありません。
- 写真は長辺1000pxのJPEGに縮小して保存します。容量を超える場合は保存せず、画面に通知します。
- 運営画面を別タブで開くと、登録・削除が利用者画面へ即時反映されます。
- 「カメラで撮影」は `capture` 属性による端末のカメラ起動です。対応していない環境ではファイル選択になります。
- 印刷はブラウザーの印刷ダイアログを使います（A4）。名札は切り取って使う想定です。
- 引換券の受け渡しと商品の受け取りは会場で行う想定です。アプリ内では在庫や受け取りを管理しません。
- デモデータの初期化は運営画面の末尾から行えます。
- 登場する人物・商品は架空です。顔写真はデモ用のイラストです。

## Cloudflare Workers

`wrangler.jsonc` が `dist` を静的アセットとして配信します。Worker のコードはありません。

- 手動デプロイ： `npx wrangler login` のあと `npm run deploy`
- GitHub 連携： Workers & Pages → Create → Import a repository でリポジトリを選び、ビルドコマンドは空、デプロイコマンドは `npx wrangler deploy`、ルートディレクトリは `/`、プロダクションブランチは `main`
- 公開先： `https://meguru-danchi.<アカウントのサブドメイン>.workers.dev`
